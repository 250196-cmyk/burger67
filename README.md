# Burger.com

A static Russian-language burger recipe website with a dark restaurant-inspired theme.

## Open locally

Open `gbdgd.html` for the home page, or start a local server from this folder:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000/gbdgd.html. The recipe catalog is available at
`/рецепты.html`; ingredients, burger information, and videos have their own pages.

The catalog includes recipe search and filters, saved favorites, recipe details,
serving-size adjustment, a cooking timer, and print support. Decorative motion can
be disabled with the on-page animation control and respects reduced-motion settings.
